# Landing Pages Collection

4 responsive landing page templates built with HTML, CSS, and vanilla JavaScript.

Built with AI assistance (Gemini + DeepSeek) as design experiments.
No frameworks. Single-file. Fully responsive.

---

## Tech Stack

- HTML5
- CSS3 (custom properties, animations, flexbox, grid)
- Vanilla JavaScript (no frameworks)
- Google Fonts
- Font Awesome icons

---

## Features

- Fully responsive (mobile, tablet, desktop)
- Dark theme with custom gradients
- Smooth scroll and intersection observer animations
- Interactive tabs, custom cursors, and floating elements
- No build tools required — open any `index.html` directly

## Usage

1. Clone the repo:
   ```bash
   git clone https://github.com/0x9z/landing-pages.git
   ```
2. Open any folder's `index.html` in a browser
3. Or deploy to GitHub Pages, Netlify, or Vercel
